# ContaBancaria-Unopa

## JavaApplicationConfigurado

Este projeto é uma aplicação Java simples de gerenciamento bancário via console. Ele permite que o usuário registre informações básicas (nome, sobrenome e CPF) e realize operações como consulta de saldo, depósito e saque. Ao encerrar o programa, uma mensagem de despedida é exibida.

## Funcionalidades
- Cadastro de usuário (nome, sobrenome e CPF)
- Consulta de saldo
- Realização de depósito
- Realização de saque
- Encerramento do programa com mensagem de despedida

## Como executar

1. Abra sua IDE Java (NetBeans, Eclipse, VS Code ou outra).
2. Crie um novo projeto Java com o nome `JavaApplicationConfigurado`.
3. Adicione uma nova classe chamada `BancoApp`.
4. Copie e cole o código fonte disponível no arquivo `BancoApp.java`.
5. Execute o projeto.

## Estrutura de Classes

- `Usuario`: armazena os dados do usuário (nome, sobrenome e CPF).
- `ContaBancaria`: permite depósito, saque e consulta de saldo.
- `BancoApp`: classe principal com menu interativo via console.

## Tecnologias Utilizadas

- Java SE (Standard Edition)
- Console (System.in / System.out)
